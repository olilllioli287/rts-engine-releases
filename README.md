# RTS Engine

一款從零寫起的即時戰略遊戲，玩法照《星海爭霸 II》對戰版：人類、蟲族、神族三個種族，
可以對戰電腦、和朋友連線 1v1，或兩個人同隊 2v2 打電腦。

這個頁面只放安裝檔。畫面是自己畫的圖形，沒有附任何暴雪的美術或音效。

## 下載

到 [Releases](../../releases/latest) 下載最新版：

- **Windows**：`RTS-Engine-Setup.exe` 是安裝程式，不需要系統管理員權限，會建立開始選單和桌面捷徑，
  可以從「設定 → 應用程式」解除安裝。安裝程式沒有數位簽章，Windows 會跳出「Windows 已保護您的電腦」，
  按「其他資訊」→「仍要執行」。不想安裝的話，`RTS-Engine-windows.zip` 解壓後直接執行 `rts.exe` 也可以。
- **Mac（Apple 晶片，M1 以後）**：`RTS-Engine-x.y.z.zip`，解壓後點兩下 `RTS Engine.app`。
  第一次開啟如果被 macOS 擋下，到「系統設定 → 隱私權與安全性」往下捲，按「仍要打開」。

Mac 和 Windows 可以互相連線。**連線的兩邊必須是同一個版本**，版本不同時遊戲會直接告訴你。

**更新**：0.10.1 以後的版本，打開遊戲時主選單右上角會提示新版本。Windows 點一下就會自動下載、安裝、重開；Mac 會打開這個下載頁。

## 怎麼玩

打開後是主選單：對戰電腦、觀看電腦對打、看以前的錄影、區網連線。「地圖」「種族」「難度」按鈕點一下就切換。
遊戲中按 F10 開選單；分出勝負後按 Enter 回主選單。

### 和朋友連線

一個人按「區網連線：開主機」，選單上會顯示一個位址；另一個人在「加入」那一格輸入這個位址再點下去。
連上之後會先進「連線房間」：主機選模式（1v1 對打或 2v2 一起打電腦）、地圖、視野迷霧開關、電腦的種族與難度，兩邊各自選種族，主機按「開始遊戲」才開打。

### 不在同一個網路：用 Tailscale 連線

在同一個 Wi-Fi 下直接連就好。不在同一個地方時，用 [Tailscale](https://tailscale.com)（免費）讓兩台電腦像在同一個區網：

1. **兩個人都安裝 Tailscale**：到 <https://tailscale.com/download> 下載（Mac、Windows 都有），打開後用 Google、Microsoft 或 GitHub 帳號登入。
2. **開主機的人邀請對方**：用瀏覽器打開 <https://login.tailscale.com/admin/users>（第一次會先問使用目的，隨便選，例如個人使用），
   按「Invite external users」產生邀請連結，傳給朋友。
3. **朋友打開邀請連結**，用自己的帳號登入、加入。之後在 Tailscale 的裝置列表會看到兩台電腦，各有一個 `100.` 開頭的位址。
4. **開主機的人**在遊戲按「區網連線：開主機」（選單上也會顯示自己的 `100.x.x.x` 位址）。第一次電腦會問要不要允許連入連線，要按允許。
5. **朋友**在「區網連線：加入」那一格輸入主機的 `100.x.x.x` 位址，再點下去。

小提醒：
- 兩邊版本要一樣。從 0.12.0 起，主選單右上角有新版時會出現更新按鈕，按一下就會更新。
- Tailscale 有時會經過轉送站（例如香港），延遲一百多毫秒，指令會稍微慢一點反應，但兩邊畫面不會跑掉。
- 連不上時：確認兩台電腦的 Tailscale 都是「Connected」，以及位址打的是主機那台的。
- 遊戲中畫面上方會顯示指令延遲和往返時間；網路變慢時遊戲會自動加大指令延遲，避免停頓。
- 畫面不順的電腦：主選單左上角把「畫質」切到「標準」，重開遊戲。

### 2v2：兩個人一起打電腦

主選單的「地圖」切到「**四方要塞（2v2）**」：

- 「區網連線：開主機」：你和加入的朋友同隊，對兩台電腦。電腦的種族和難度看主機選單上的「電腦 Y」和「難度」。
- 「對戰電腦」：你和一台電腦隊友，對兩台電腦。
- 「觀看電腦對打」：四台電腦對打，按 V 輪流切換四個人的視野。

隊友之間共享視野。你先被打掉的話隊友還會繼續打，兩個人都被打掉才算輸。

## 種族

- **人類**：太空工程車留在原地蓋建築、可以修理；補給站可以降下；陸戰隊戰鬥藥劑（T，要先在兵營的科技實驗室研發）、攻城坦克攻城模式（E）／坦克模式（D）；兵營、軍工廠、星際港可以接科技實驗室（X）或反應爐（C）；蓋建築的太空工程車按 T 暫停。
- **蟲族**：孵化所長幼蟲，幼蟲變成單位；工蟲變成建築；蟲族建築要蓋在蟲苔上；后蟲注射（V）與蟲苔瘤（C）。
- **神族**：探測機召喚建築後就能離開；建築要在水晶塔的能量場內才能運作；單位有護盾；星核超時空加速（C）。
- **防禦建築**：人類碉堡、飛彈砲台；蟲族脊刺爬行蟲、孢子爬行蟲；神族光子加農砲、護盾充能器。陸戰隊進碉堡射程 +1、不會被打到。
- **核心兵種**：人族醫療艇（治療、載兵）、蟲族毒爆蟲（異化蟲變形、自爆）、神族教士（幽能轉移瞬移）。
- **空軍**：人類星際港＋女妖轟炸機、蟲族螺旋塔＋飛螳（攻擊會彈跳）、神族星際之門＋虛空艦。狂戰士、異化蟲、蟑螂這些近戰和地面兵打不到空中。
