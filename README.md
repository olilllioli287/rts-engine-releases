# RTS Engine

一款從零寫起的即時戰略遊戲，玩法照《星海爭霸 II》對戰版：人類、蟲族、神族三個種族，
可以對戰電腦、和朋友連線 1v1，或兩個人同隊 2v2 打電腦。

這個頁面只放安裝檔。畫面是自己畫的圖形，沒有附任何暴雪的美術或音效。

## 下載

到 [Releases](../../releases/latest) 下載最新版：

- **Windows**：`RTS-Engine-Setup.exe` 是安裝程式，不需要系統管理員權限，會建立開始選單和桌面捷徑，
  可以從「設定 → 應用程式」解除安裝。安裝程式沒有數位簽章，Windows 會跳出「Windows 已保護您的電腦」，
  按「其他資訊」→「仍要執行」。不想安裝的話，`RTS-Engine-windows.zip` 解壓後直接執行 `rts.exe` 也可以。
- **Mac（Apple 晶片，M1 以後）**：`RTS-Engine-x.y.z.zip`，解壓後點兩下 `RTS Engine.app`。
  第一次開啟如果被 macOS 擋下，到「系統設定 → 隱私權與安全性」往下捲，按「仍要打開」。

Mac 和 Windows 可以互相連線。**連線的兩邊必須是同一個版本**，版本不同時遊戲會直接告訴你。

## 怎麼玩

打開後是主選單：對戰電腦、觀看電腦對打、看以前的錄影、區網連線。「地圖」「種族」「難度」按鈕點一下就切換。
遊戲中按 F10 開選單；分出勝負後按 Enter 回主選單。

### 和朋友連線

一個人按「區網連線：開主機」，選單上會顯示一個位址；另一個人在「加入」那一格輸入這個位址再點下去。
雙方各自用「種族」按鈕選自己的種族（「你 X」那一邊）。

**不在同一個網路時**：兩個人都裝 [Tailscale](https://tailscale.com)（免費），登入後把裝置分享給對方，
兩台電腦就像在同一個區網。主機選單上會多顯示一個 `100.x.x.x` 的位址，給對方輸入這個。
第一次開主機時，電腦可能會問要不要允許連入連線，要按允許。

### 2v2：兩個人一起打電腦

主選單的「地圖」切到「**四方要塞（2v2）**」：

- 「區網連線：開主機」：你和加入的朋友同隊，對兩台電腦。電腦的種族和難度看主機選單上的「電腦 Y」和「難度」。
- 「對戰電腦」：你和一台電腦隊友，對兩台電腦。
- 「觀看電腦對打」：四台電腦對打，按 V 輪流切換四個人的視野。

隊友之間共享視野。你先被打掉的話隊友還會繼續打，兩個人都被打掉才算輸。

## 種族

- **人類**：太空工程車留在原地蓋建築、可以修理；補給站可以降下；陸戰隊戰鬥藥劑（T）、攻城坦克攻城模式（D）。
- **蟲族**：孵化所長幼蟲，幼蟲變成單位；工蟲變成建築；蟲族建築要蓋在蟲苔上；后蟲注射（V）與蟲苔瘤（C）。
- **神族**：探測機召喚建築後就能離開；建築要在水晶塔的能量場內才能運作；單位有護盾；星核超時空加速（C）。

## 操作（照星海2 習慣）

| 操作 | 按鍵 |
|---|---|
| 選取／框選 | 左鍵點選、拖曳；Shift 加選；雙擊或 Ctrl+點 選畫面上同類 |
| 移動、攻擊、採礦、集結 | 右鍵（點敵人＝攻擊，點礦＝採礦，點自己的單位＝跟隨，選建築時＝集結點，點未完成建築＝接手施工） |
| 攻擊移動 | A 再左鍵 |
| 巡邏 | P 再左鍵：在兩點之間來回，路上遇敵就打 |
| 停止／原地待命 | S／H |
| 建造（人類） | 選太空工程車按 B，再按 Q 補給站、W 兵營、E 軍工廠、R 指揮中心、T 電機工程所、A 瓦斯精煉廠，左鍵放置 |
| 建造（蟲族） | 選工蟲按 B，再按 H 孵化所、S 孵化池、E 瓦斯萃取巢、R 蟑螂繁殖場、V 進化室、D 刺蛇獸穴 |
| 建造（神族） | 選探測機按 B，再按 N 星核、E 水晶塔、A 瓦斯處理廠、G 傳送門、Y 機械控制核心、F 冶煉廠、R 機械製造廠 |
| 生產 | 選建築按卡片上標的鍵（人類 Q／W；蟲族幼蟲 D 工蟲、V 王蟲、Z 異化蟲、R 蟑螂、H 刺蛇，孵化所 Q 后蟲、L 蟲穴、S 選幼蟲；神族 E 探測機、Z 狂戰士、S 追獵者、I 不朽者） |
| 研究 | 選研究建築按 Q／W／E；Esc 取消（全額退款） |
| 編隊 | Ctrl（或 Cmd）＋數字 設定，數字 叫出，連按兩下 鏡頭跳過去 |
| 其他 | F1 閒置工兵（Ctrl+F1 全部）、Backspace 切換基地、F2 全部軍隊、空白鍵 鏡頭到選取、F9 全圖視野、F7 切換多核心、M 靜音、+/- 速度、F10 選單 |
| 鏡頭 | 方向鍵、中鍵拖曳、點小地圖、滾輪縮放；F8 開啟滑鼠碰邊捲動 |

Shift 加在任何指令上＝排進佇列。
